The last project of the session, so it uses everything. Compare it

is one line: a comprehension, or filter() with a lambda.

-----------------------------------------------------
GOAL
-----------------------------------------------------
A teacher has the class's marks in a CSV file. Build a tool that reads
the file and answers the questions a teacher asks: who is first, what
is the class average in each subject, who topped each subject, who
failed and in what, who got a distinction. Then save it all as a
report.

This project is the PRIORITY 2 practice: almost every answer is one
comprehension or one built-in with a lambda.

-----------------------------------------------------
MODULE TOPICS THIS PROJECT PRACTISES
-----------------------------------------------------
PRIORITY 2
comprehensions     -> list: the failed subjects, the search results
                      dict: subject averages, subject toppers, grade
                            counts
                      set:  spotting a repeated subject in the header
built-ins          -> zip()       pair each subject with its mark
                      map()       int() on every mark in a row
                      enumerate() line numbers for the warnings,
                                  rank numbers for the rank list
                      sorted()    the rank list
                      filter()    the students who failed
                      any()       has the student got a distinction?
                      all()       did the student pass every subject?
                                  are all the marks from 0 to 100?
                      sum() max() min() len()
lambda             -> sort key (-total, name), the filter test, the
                      max() key for each subject's topper

PRIORITY 1
OOP                -> a Student class: name and marks as attributes;
                      total(), average(), passed(), has_distinction(),
                      failed_subjects(), grade() as methods
exception handling -> a custom MarksFileError; ValueError from int()
                      turned into a clear message; a missing file, a
                      folder instead of a file, a file that isn't text
file handling      -> read the CSV line by line with "with open(...)",
                      write the report to a text file
os                 -> paths built from __file__ with os.path.join,
                      os.makedirs, os.path.exists, os.path.abspath to
                      show the full path of a relative one

-----------------------------------------------------
REQUIREMENTS
-----------------------------------------------------
1. Menu:
      1. Rank list                  5. Save the full report
      2. Subject summary            6. Load another CSV file
      3. Failed and distinctions    7. Quit
      4. Find a student
2. CSV format: the first line is "name,subject1,subject2,..." (any
   number of subjects), then one line per student.
3. First run: create a sample marks.csv in practice_files/.
4. Bad lines are skipped with a warning that gives the line number:
   wrong number of marks, a mark that isn't a whole number, a mark
   outside 0-100, an empty name, a name that appears twice.
   Blank lines are ignored.
5. The file can't be used at all (show why, don't crash) when: it
   doesn't exist, it's empty, the header doesn't start with "name",
   there are no subjects, or a subject appears twice.
6. Rules:
      pass         -> at least 35 in EVERY subject
      distinction  -> 90 or more in ANY subject
      grade        -> from the average: A+ 90, A 80, B 70, C 60,
                      D 50, E 35; F for anyone who failed a subject
7. Rank list: highest total first; equal totals in name order.
8. Subject summary: average, topper and their mark, for each subject.
9. Find a student: case-insensitive, matches part of the name.
10. The report (practice_files/report.txt) has all of the above, plus
    the grade counts and the pass rate.
