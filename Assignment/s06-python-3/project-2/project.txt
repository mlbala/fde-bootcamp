-----------------------------------------------------
GOAL
-----------------------------------------------------
Everyone's Downloads folder ends up a mess. Build a tool that sorts the
files in a folder into sub-folders by type (Images, Documents, Audio,
Video, Archives, Code, Other), shows the plan before moving anything,
and can undo everything it did.

It starts on a practice folder full of sample files, so it is safe to
try. Only point it at a real folder once you trust it.

-----------------------------------------------------
WHAT IT PRACTISES
-----------------------------------------------------
TOPIC 2: OS (the main topic)
os.getcwd()            where relative paths start from
os.path.abspath()      relative path -> full path
os.path.expanduser()   "~/Downloads" -> full path
os.path.join()         build paths that work on Windows, macOS, Linux
os.listdir()           what's in the folder
os.path.isfile() / isdir() / exists()
os.path.splitext()     "photo.JPG" -> ("photo", ".JPG")
os.path.relpath()      full path -> "Images/photo.JPG"
os.makedirs(exist_ok=True), os.rename(), os.remove(), os.rmdir()

TOPIC 3: FILE HANDLING
- a JSON log of every move: json.dump() / json.load() with "with"
- "x" mode to create the sample files without ever overwriting one

TOPIC 1: EXCEPTION HANDLING
- NotADirectoryError for a folder that doesn't exist
- OSError for a file that can't be moved: report it, move the rest
- FileNotFoundError for a missing log (normal: nothing to undo yet)
  and for a file that was deleted before undo
- a custom LogError for a broken log, raised BEFORE anything moves
- finally, so the log is written even if the loop stops halfway

-----------------------------------------------------
REQUIREMENTS
-----------------------------------------------------
1. Menu:
      1. Create sample files     4. Undo
      2. Preview                 5. Choose another folder
      3. Organize                6. Quit
2. Only the files directly inside the folder are organized: not
   sub-folders, not hidden files (names starting with "."), and not
   the tool's own log file.
3. The category comes from the extension, ignoring case
   ("photo.JPG" -> Images). No extension or an unknown one -> Other.
4. Preview lists what would move where, grouped by category in the
   order of CATEGORIES, and moves nothing.
5. Organize shows the preview, asks "Move N files? (y/n)", then moves.
   - A category folder is created only when it's needed.
   - A file is NEVER overwritten: if "Images/photo.jpg" already exists,
     the new one becomes "Images/photo (1).jpg".
   - If one file can't be moved, report it and carry on with the rest.
6. Every move is recorded in organizer_log.json inside the folder.
   Undo moves every recorded file back (newest first), removes the
   category folders it left empty, and deletes the log.
7. A broken log (not valid JSON, or entries that point outside the
   folder) raises LogError, and nothing is moved.
8. "Choose another folder" accepts a full path, a relative path or a
   path starting with ~, and always prints the full path it will use.
